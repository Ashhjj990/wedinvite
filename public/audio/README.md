# Wedding Invitation Video Assets

This folder is reserved for your cinematic opening video.

Recommended file:
- public/videos/wedding-intro.mp4

The site currently uses a remote placeholder video URL, but you can replace it with your own file by updating the `<source>` in `index.html`.

Example:
```
<source src="public/videos/wedding-intro.mp4" type="video/mp4" />
```

You can also replace the background music in `index.html` with your own audio file.
