# Wedding Invitation Audio Assets

This folder is reserved for your ceremony or background music.

Recommended file:
- public/audio/wedding-music.mp3

The page currently uses a remote music placeholder. Replace the audio source in `index.html` with your own file when ready.

Example:
```
<audio id="bgMusic" loop preload="none">
  <source src="public/audio/wedding-music.mp3" type="audio/mpeg" />
</audio>
```
